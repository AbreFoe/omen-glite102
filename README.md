# GLite ✨

Маленький и уютный настройщик для **Logitech G102 LIGHTSYNC** — вместо тяжёлого G HUB (｡•ᴗ•｡)

Один exe на ~5 МБ, в трее ест ~14 МБ памяти. Tauri 2 (Rust + системный WebView2), интерфейс в стиле Material You.
Также должна подойти G102 Prodigy / G203.

## Что умеет

- **DPI**: до 5 уровней (50–8000, шаг 50), уровень по умолчанию, уровень «Снайпера». Изменения видны сразу.
- **Частота опроса**: 125 / 250 / 500 / 1000 Гц.
- **Подсветка**: выкл / статичный цвет / дыхание / радуга, скорость и яркость. Предпросмотр сразу на мыши.
- **Кнопки** (кроме левой): любой клик мыши, переключение DPI, DPI +/−, снайпер, отключение — или **действие GLite**:
  сочетание клавиш, медиаклавиши, ввод текста, макрос (запись с паузами; один раз / пока зажата / вкл-выкл), запуск программы или ссылки,
  Discord: вкл/выкл микрофон, вкл/выкл звук, рация (push-to-talk).
- Тема строится из цвета подсветки (или выбранного цвета), светлая/тёмная/системная.
- Сворачивается в трей, автозапуск с Windows.

## Как это работает

Настройки DPI, частоты, подсветки и назначения кнопок записываются во **встроенную память мыши** (onboard profile, HID++ 2.0 `0x8100`),
так что они работают и без запущенной программы, и на другом компьютере.

Кнопки с «действием GLite» мышь отправляет как клавиши **F13–F18** (кнопка N → F12+N). GLite перехватывает их хуком клавиатуры
и выполняет действие. Без запущенного GLite эти кнопки ничего не делают.

Перед первой записью GLite сохраняет исходный профиль мыши в `%APPDATA%\GLite\profile-backup.bin` —
«Настройки → Восстановить исходный» вернёт его. Конфиг: `%APPDATA%\GLite\config.json`.

## Discord

- **Горячие клавиши** (просто): в Discord → Настройки → Горячие клавиши назначь «Вкл/выкл микрофон» и «Вкл/выкл звук»
  на редкие сочетания (например Ctrl+Shift+F9), и такие же запиши в GLite на вкладке Discord.
- **Discord RPC** (точное управление и состояние): создай приложение на discord.com/developers/applications,
  в OAuth2 скопируй Client ID / Client Secret, добавь Redirect `http://localhost`, вставь в GLite и нажми «Подключить».

## Сборка

```bash
cd src-tauri
cargo build --release
```

Готовый файл: `src-tauri/target/release/glite.exe` (один exe, установка не нужна).

## Важно

Закрой и лучше удали G HUB — он перезаписывает профиль мыши своими настройками.
Если подсветка не меняется, выключи в Windows «Параметры → Персонализация → Динамическое освещение» для мыши.
